# Pendiente de entregar

Este documento lista lo que falta por entregar del proyecto, junto con la razón de cada punto.

## 1. Rutas turísticas

**Qué falta:** mostrar en la página de Rutas (`routes.html`) las rutas turísticas del sistema, con sus horarios y conexiones de transporte. Por ahora la página solo muestra el título, el header y el footer.

**Por qué no se ha entregado:**
- No se ha agregado por completo la lógica de Prolog que arma las rutas.
- No se ha definido cómo se van a presentar gráficamente en la página.

## 2. Limpiar la base de conocimientos

**Qué falta:** que el botón "Limpiar Base de Conocimientos" de la página de Inicio borre los datos de la base de conocimientos. El botón ya existe en la interfaz, pero todavía no tiene ninguna acción conectada.

**Por qué no se ha entregado:**
- No se ha agregado por completo la lógica de Prolog necesaria para esta operación.
- No se ha definido cómo se va a presentar gráficamente.

## 3. Estadísticas

**Qué falta:** todas las estadísticas del sistema, que se calculan con Python.Incluyen:
- Turistas de mayor frecuencia a un destino.
- Todos los turistas de un guía.
- Destinos relacionados con un destino específico.
- Todos los destinos de un turista.

**Por qué no se ha entregado:**
- Aún se está definiendo cómo se van a presentar en la interfaz.

## Lo que se necesita para poder entregarlos
- Terminar de agregar la lógica de Prolog para las rutas y para limpiar la base de conocimientos.
- Definir cómo se van a presentar gráficamente las rutas, la limpieza de la base de conocimientos y las estadísticas.

- **Limpiar la base de conocimientos:** La lógica de Prolog no está agregada por completo y no se ha definido su presentación gráfica.
